# 📝 Sistema Conecta Bairro - Gestão de Ocorrências

Este projeto é um sistema em Java desenvolvido para gerenciar reclamações e problemas comunitários em bairros (como buracos na rua, falta de iluminação, vazamentos, etc.). 

O objetivo principal foi consolidar os aprendizados práticos sobre estruturas de dados, focando no uso de coleções do tipo `Map` e `List`, além de enumerações e tratamento de exceções.
O intuito era simular um banco de dados local utilizando a estrutura Map, já que ela permite armazenar pares de chave e valor.

## Tecnologias e Conceitos Aplicados
* **Java SE**
* **Coleções:** Uso de `LinkedHashMap` para vincular usuários às suas listas de ocorrências.
* **Enumerações (Enums):** Definição padronizada de títulos e status das ocorrências.
* **ConsoleUtils:** Tratamento de erros de entrada (`InputMismatchException`) para garantir uma navegação segura no menu via console.
